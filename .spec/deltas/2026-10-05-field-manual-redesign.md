# Delta — Infrastructure Field Manual Redesign

**Date:** 2026-10-05

## Affected Specs

- `.spec/PRD.md`
- `.spec/DESIGN.md`
- `.spec/TASKS.md`

## Before

The first redesign retained the dark control-plane system, used a marketing-funnel homepage, and moved exhaustive content into `/evidence`.

## After

The replacement uses a warm editorial field-manual system, evidence plates, a sequential flagship narrative, `/work` and `/about`, technical dossiers, and an `/evidence` redirect.

## Rationale

User review and portfolio research found the first implementation clearer but still visually generic and insufficiently authored.

## Impact

Presentation, navigation, homepage components, case template, social artwork, and acceptance tests change. Existing content sources and case URLs remain.
